# apps/web

The frontend — React + Vite + TypeScript + TanStack Query, styled from the tokens in
[`design/synapse/`](../../design/synapse). See the [repo root README](../../README.md)
for how to run the whole project (backend included) and the full stack.

```bash
npm run dev    # Vite dev server
npm run build  # tsc -b && vite build
npm run lint   # eslint
npm test       # vitest
```
