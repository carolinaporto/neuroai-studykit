A short personal note or "aha" moment, kept in the Notes & Insights tab. Consumer provides the discipline tag(s), the note body, an optional linked week/source, and its access state.

Tag every note by which of the course's three lenses it belongs to — `Neuroscience`, `Computer Science`, `Psychology`, or a combination joined with " · " as shown — set in `tag` on `surface-200`, never a color the reader could mistake for `accent-neuro` or `accent-warm`; discipline is a category, not an action or a public/private signal. The `AccessBadge` sits at the opposite corner and defaults to `Private`; a note only becomes `Public` when its author explicitly marks it so (a note referencing locked lecture content usually shouldn't be).

Body copy is `body-sm`, three lines before truncating in a list view; title is `h3`. The footer rule + "Linked to Week N" caption is optional — omit it for a free-floating note not tied to a specific week's material.
