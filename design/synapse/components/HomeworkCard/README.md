A homework entry in the public portfolio — the research write-ups meant to be shown alongside the GitHub repo, outside the locked part of the site. Consumer provides the week, title, discipline tags, a short description and the code/live links.

Always carries the `Public` `AccessBadge` (`accent-warm` on `accent-warm-soft`) — this is the one card type that defaults public, so don't add a private variant; a homework entry that must stay unlisted belongs in Notes & Insights instead, not a hidden state of this card. Discipline tags reuse `InsightNote`'s neutral `surface-200` chip, split into separate chips here rather than one joined string, since a homework brief more often spans exactly two of the three lenses. Footer links are `accent-warm`, matching the badge — the one place this system lets an accent double as a link color, because the link's whole point is "this is the public part."

Title is `h3`, description `body-sm`, three lines max before truncating on an index page.
